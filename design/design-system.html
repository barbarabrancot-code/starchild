Every role is regular — there is no bold in this type system. Hierarchy is carried entirely by size, color and case: 56px white for the Title, 32px orange all-small-caps for the Subtitle Eyebrow, 21px grey for Body. So emphasis inside a paragraph means switching the text from grey to white (.type-body--strong), not bolding it. Headings inherit regular too — <h1>–<h4> are no longer bold by default.

Leading is 120% on every role, at both breakpoints. Being a ratio rather than a pixel value, it follows the size on its own — so unlike the sizes, no leading needs a clamp(). Tracking is likewise constant: 1% on the titles, 2% on the eyebrow and body.

The one exception is UI chrome: buttons and nav sit at medium (500), since a 16px label in a filled button needs a little more presence than body copy. Nothing in the four roles uses it. If you want those regular too, it is two lines.

One hierarchy consequence of the new mobile sizes: the Eyebrow and Body are both 14px on mobile. The eyebrow is no longer distinguished by size there — only by color and all-small-caps. That works, but it means the orange and the letterform are doing all the work, so an eyebrow that loses its color loses its role entirely.

Interpolation

The two values become one clamp() anchored at 375px (mobile) and 1440px (desktop). Between them the size grows continuously; outside them it locks. No font-size jump at any breakpoint.

/* Title size: 24px @375 → 56px @1440 */
--text-title: clamp(1.5rem, .7958rem + 3.005vw, 3.5rem);

/*  375px → 24.0px  (locks here going down)
    768px → 35.8px
   1024px → 43.5px
   1440px → 56.0px  (locks here going up)  */

/* Leading needs no clamp: 120% is a ratio, so it tracks
   whatever the size resolves to at that viewport. */
--leading-title: 1.2;   /* 28.8px @375 … 67.2px @1440 */

The key to the system: content is locked at 1296px and centered. The 312px margin is not a value you write — it happens when the screen is 1920 wide. At 1440 the same rule yields 72px. One max-width covers both screens.

.container {

  max-width: var(--container-max);   /* 1296px */
  margin-inline: auto;

Why 1440 needs no rule of its own

The 72px margin at 1440 and the 312px margin at 1920 come from the same line of CSS. Locking content at 1296px and centering it already produces both — writing a breakpoint at 1440 would only create another number to keep in sync by hand.

Hard rules: no min-width larger than the screen; tables, code and diagrams inside overflow-x:auto; the body never scrolls horizontally.
