Artwork for the "Works with what you already use." carousel.

One PNG per connector, named by its id:

  gmail.png  gcal.png  gdrive.png  notion.png  slack.png  telegram.png

The plate is 420px tall and the image is fitted inside it with max-width and
max-height, so any shape works — landscape reads best. Nothing needs importing:
the section tries the file and falls back to naming it if it is not there yet,
so drop one in and it appears.

The order the six are shown in is SLIDES in
src/prototype/landing/f/OrbitSection.tsx.
