# Registro de Alterações — 07/09/2026 17:40

Escopo: só as mudanças que afetam `onboarding.html`.

## Resumo
Novo link dedicado que sempre mostra o layout mobile do onboarding, do tamanho de um celular (390×800), não importa a largura da janela de quem abre. Nele, os gestos de segurar/tocar/arrastar nas mensagens funcionam também pelo mouse — em qualquer outro lugar do site, um mouse continua usando a barra de ícones normal, só nesse link específico é que ele passa a se comportar como toque.

## Alterações por Variante/Módulo

### B/Entry
- Arquivos adicionados: `onboarding-mobile.html`
- Arquivos modificados: `vite.config.ts`
- O que mudou:
  - Nova página que carrega o `onboarding.html` de verdade dentro de uma moldura de celular (390×800, encolhendo só se a tela real for menor). Num celular de verdade, a moldura some e a página ocupa a tela inteira.
  - Registrada como ponto de build próprio em `vite.config.ts`, pra sair publicada junto com o resto do site.

### B/Chat
- Arquivos modificados: `src/prototype-b/Reactable.tsx`
- O que mudou:
  - Os gestos de reagir/copiar/responder nas mensagens (tocar, segurar, arrastar) trocaram de Touch Events pra Pointer Events, que tratam mouse e toque com o mesmo código. Isso permite ao novo link mobile (`?touchDemo=1` na URL) fazer o mouse se comportar como dedo — só nessa página; no resto do site, um mouse continua usando a barra de ícones no hover, sem mudança de comportamento.
